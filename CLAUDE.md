# trie-project

Учебная реализация префиксного дерева (Trie) на Java для подготовки к собеседованиям.

## Сборка и тесты

```bash
mvn -q -B test        # прогнать тесты
mvn -q -B compile     # только компиляция
mvn -q -B clean test  # с нуля
```

Отдельный тестовый класс или метод:

```bash
mvn -B test -Dtest=TrieTest
mvn -B test -Dtest='TrieTest$Delete'
```

## Окружение

- Maven 3.9.12, работает на **JDK 25** (Homebrew) — это то, что требует `pom.xml` (`maven.compiler.release=25`).
- Команда `java` в PATH указывает на **JBR 21** (JetBrains Runtime от IDEA). Версии не совпадают,
  но на сборку это не влияет: Maven использует свой JDK. Запускать классы напрямую через `java`
  без указания версии не стоит.

## Устройство Trie

- Узел хранит детей в `HashMap<Character, Node>`, а не в `char[26]` — чтобы работали
  кириллица и любой unicode. Это осознанный выбор, не переписывать на массив.
- `passCount` — сколько слов проходит через узел; нужен, чтобы при удалении освобождать
  ненужные узлы.
- `endCount` — сколько слов заканчивается в узле; больше единицы, если слово вставлено
  несколько раз. Дубликаты разрешены.
- `size()` считает слова **с учётом дубликатов**.
- `insert` и `search` игнорируют `null` и пустую строку.
- Поиск чувствителен к регистру.

## Стиль

- Комментарии и `@DisplayName` — на русском, код и имена — на английском. Придерживаться.
- Тесты на JUnit 5 с `@Nested` по группам операций, ассерты — AssertJ (`assertThat`).
- Для граничных случаев используются `@ParameterizedTest` с `@NullAndEmptySource`.
- Разделители-комментарии вида `// ---- insert` между блоками — часть принятого стиля.
